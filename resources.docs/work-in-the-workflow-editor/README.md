# Work in the Workflow Editor - Open, Edit, Run, and Read Your Bots

Welcome! 👋

The workflow editor is the canvas where you build a bot out of steps. You drag steps from a toolbox, set their fields, run the whole bot, and read the report. This path shows every way to open a bot, how the canvas and the bot file stay in step, how to shape the toolbox, and where to look when something goes wrong.

Plan for about **37 minutes**.

---

## Who is this for?

Anyone who has a G4 project and wants to work comfortably with the canvas. You do not need to write code. You should have built one bot before, for example in the Quick Start path.

## What you'll do

By the end you will be able to:

- Open a bot in three ways and know which one writes your edits back to the file
- Edit on the canvas and in the text of the same file, and use Undo
- Hide the toolboxes and tools you never use, for yourself or for the whole project
- Run a bot from the canvas, stop it, and reset the canvas
- Find a saved report, open it in the Report Viewer, and know why a report sometimes opens as text
- Read the two output channels and set how much the extension logs

## Prerequisites

- A G4 project open in VS Code with the **G4 extension** installed. The folder you open is the project's `src` folder
- The G4 Hub running and reachable at the address in your project's `manifest.json`. The canvas page is downloaded from the Hub every time you open a bot
- At least one bot in the `bots` folder

> **💡 New words:** A **bot** is one automation file. The **canvas** is the picture of the steps. The **designer** is the page that draws the canvas, and it comes from the Hub. A **definition** is the bot as the designer holds it.
